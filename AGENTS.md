# Библиотека лекций

## Проект

Личная публичная библиотека учебных материалов. Репозиторий хранит канонические лекции.
Сайт публикуется на GitHub Pages. Подготовка выполняется локально агентом.
Название репозитория сохранено ради постоянного адреса сайта.

## Принципы

- Библиотека относится только к явно заказанным лекциям.
- Спецификация, отчёт и материал заказчику не становятся лекцией из-за формата HTML.
- Явный запрос новой лекции включает сбор материала и публикацию на Pages.
- Перед созданием аудио спросить владельца. Прямой запрос аудио уже даёт согласие.
- Сохранить стандарты `~/.claude/rules/theory.md`, `html-pages.md` и шаблон `page.html`.
- Стандарт содержания не дублировать в проекте. Общая навигация подключается отдельно.
- Не менять исходники и незакоммиченные правки других проектов при переносе.
- Не создавать дайджесты в рамках этого проекта без отдельного запроса.

## Стек и структура

Python без внешних зависимостей, HTML, CSS и небольшой JavaScript для позиции аудио.

| Путь | Назначение |
| --- | --- |
| `library.json` | Явный каталог лекций и необязательного аудио |
| `library.py` | Сборка каталога, навигации и проверка локальных ссылок |
| `site/lectures/` | Самостоятельные страницы лекций |
| `site/assets/` | Общая навигация, стили каталога и плеер |
| `site/audio/` | Только согласованные аудиофайлы |
| `audio-scripts/` | Сценарии аудиолекций |
| `skills/learning-library/` | Связка существующих инструментов и публикации |

## Команды

- Сборка: `python3 library.py build`.
- Проверка: `python3 library.py check`.
- Тесты: `python3 -m unittest discover -s tests -v`.
- Проверка JavaScript: `node --check site/assets/player.js`.
- Локальный просмотр: `python3 -m http.server 8000 --directory site`.

## Публикация

GitHub Actions проверяет содержимое и публикует только `site/` после push в `main`.
После публикации проверить настоящую страницу и её ресурсы. Успех Actions не заменяет просмотр.
HTML без аудио не показывает плеер. Скоростью управляет штатный плеер браузера.
Позиция сохраняется только в текущем браузере, без синхронизации устройств.

## Критические инварианты

- В публичную копию не попадают ключи, рабочие адреса, персональные данные и закрытые метрики.
- Сырые источники, рабочие спецификации и полные приватные версии остаются вне репозитория.
- Состав библиотеки задаёт явный каталог, а не поиск всех HTML на компьютере.
- Локальные ссылки не выходят за `site/`; аудио должно существовать до добавления плеера.
- Платную озвучку не запускать без отдельного согласования расходов.
