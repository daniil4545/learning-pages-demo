# Библиотека лекций

Учебные HTML-страницы и выбранные аудиолекции, доступные через браузер телефона и компьютера.

Сайт: https://daniil4545.github.io/learning-pages-demo/

## Стадия

Минимальная библиотека: общий каталог, самостоятельные страницы, необязательный браузерный плеер.
Подготовка материалов выполняется на Mac. На Pages публикуются только готовые файлы из `site/`.

## Быстрый старт

Требования: Python 3.10 или новее. Внешних зависимостей у сборщика нет.

1. Собрать каталог: `python3 library.py build`.
2. Проверить результат: `python3 library.py check`.
3. Открыть локально: `python3 -m http.server 8000 --directory site`.
4. Перейти на http://localhost:8000/.

Тесты: `python3 -m unittest discover -s tests -v`.

## Добавить лекцию

1. Подготовить `site/lectures/<тема>.html` по существующему стандарту HTML-лекций.
2. Прочитать страницу перед публичной публикацией: убрать рабочие адреса, персональные данные и закрытые сведения.
3. Добавить запись в `library.json`:

```json
{
  "path": "lectures/example.html",
  "title": "Название лекции",
  "description": "На какой вопрос она отвечает.",
  "group": "Инженерная практика"
}
```

4. Выполнить сборку, проверки ссылок и браузерную проверку.
5. Отправить изменения в `main`: Actions проверит и опубликует папку `site/`.
6. Проверить публичный URL и дать его владельцу.

Явный запрос лекции включает публикацию. Аудио требует отдельного согласования.
Если оно уже запрошено, повторный вопрос не нужен.
После подготовки MP3 добавить поле `"audio": "audio/example.mp3"`.
Плеер появится при следующей сборке. Отдельного переключателя скорости нет.

Каноническая копия новой лекции хранится здесь. Рабочая папка на Mac остаётся git-копией библиотеки.
Повторно переносить изменения из старой локальной коллекции автоматически нельзя.
