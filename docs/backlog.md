# Открытые задачи

## Качество русской озвучки

Шаг: Обсудить.
Текущие сценарии подкастов приняты как формат. Голос macOS тестовый и владельцу не нравится.
Сравнить несколько доступных локальных голосов на одном коротком сценарии.
Выбрать голос по прослушиванию владельцем до массовой генерации.
Платные API и расходы согласовать отдельно. Материалы прежнего исследования находятся в соседнем форке аудиокурсов.

## Несколько аудиоэпизодов

Условие старта: первая лекция с аудио длиннее пяти минут.
Делить материал по темам, каждый эпизод до пяти минут с завершённым объяснением.
Каталог и плеер пока поддерживают один файл на лекцию. При первом таком выпуске добавить несколько частей.
