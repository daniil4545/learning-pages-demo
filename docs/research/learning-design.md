| Метод | Вывод и ограничения |

| Интервалы | Распределённая практика помогает сохранению [1]; универсального расписания 1/3/7 нет |

## Подача CS50

Изучены фрагменты транскриптов осени 2024 года из CS50x 2025:

1. Memory: сравнение чисел и строк, неожиданный результат, адреса, strcmp [9].
2. Data Structures: рост массива, нехватка места, цена вариантов, связанный список [10].
3. SQL: знакомые данные в Python и SQL; замер до и после индекса [11].

Приняты для текста и аудио: конкретная задача перед абстракцией; новое понятие после
ограничения знакомого решения; сквозной пример; небольшое изменение за шаг;
возвращение к знакомому глубже; цена решения; естественные вопросы и разбор ответов.
Это ориентир, не обязательная драматургия. Ошибки ради схемы не придумывать.
Полный анализ видеопостановки не проводился. Популярность курса не доказывает эффективность приёмов.

## Визуал

Сандерсон требует объясняющей цели каждого движения [12].
Примеры: геометрия связывает матрицу с перемещением векторов [13];
рисование цифры позволяет наблюдать изменение активаций сети [14].
Это референсы, не научное доказательство эффективности уроков целиком.

| Вопрос | Предложенный формат |
| --- | --- |
| Что связано? | Статическая схема |
| Что происходит? | Пошаговая анимация |
| Что будет при другом условии? | Интерактивная модель |
| Как преобразуется сложный объект? | Специальная сцена |

Готовое: браузерная анимация [15], Manim Community [16], Desmos API [17].
Для инженерных тем предложены HTML/SVG/JavaScript без отдельного видеорендера.
Manim требует окружения и рендера; автор рекомендует Community Edition [12].
Desmos подходит для графиков; API требует ключа [17]. Локальных испытаний не было.

Предложены колонка чтения, оглавление, подписи рядом с объектами, постоянные обозначения,
выделение текущего шага, остановка, повтор и статический результат.
Проверять телефон, клавиатуру и режим без движения. Эти правила ещё не утверждены.
Одна анимация и одна модель - текущее ограничение подготовки, не научная норма.

Совет Карпати про HTML и объясняющие видео найден в копии [18].
Оригинал X вернул 403; напрямую текст не подтверждён. Это совет о формате.

## Отбор и следующие шаги

Отбор делегирован агенту. Документация и стандарты подтверждают программное поведение;
учебники и курсы помогают объяснению; обзоры и исследования подтверждают научные эффекты.
Проверяются автор, актуальность, доказательства и соответствие теме [20].
Поиск расширяется при пробелах и противоречиях, без обязательной квоты ссылок.
Правила отбора и усвоения сохранены в learning-library.

После отзыва о комканности материал заменён лекцией «Реверс-инжиниринг с ИИ».
Один пример лампы раскрывается через наблюдения, гипотезы и различающие опыты.
Оставлена одна таблица данных; PS5 вынесена в приложение. Добавлены два кейса и три книги.
Аудио основного сюжета: 4:14, Silero/xenia. Проверены 390/1280, модель и плеер.
Отзыв владельца показывает ограничение формальных правил: схемы и повторение не заменяют
связную линию объяснения. Учебную модель отдельно отличаем от измерений устройства.
