## Повторная сборка

Готовое: переиспользованы ffmpeg, подготовленный русский сценарий и Silero.
Скрипт tools/render_silero.py загружает локальный файл модели без сети.
Зависимости озвучки отделены от основного сборщика; версии в tools/requirements-tts.txt.

```sh
.staging/tts-venv/bin/python tools/render_silero.py \
  audio-scripts/reverse-engineering.txt \
  .staging/reverse-engineering-silero.mp3 \
  --model .staging/tts-models/v5_5_ru.pt --voice xenia
```

Окружение и веса остаются в игнорируемой .staging; в git и на сайт не попадают.
После удаления .staging окружение создаётся через uv venv и tools/requirements-tts.txt.
Модель можно получить официальной функцией silero_tts(language="ru", speaker="v5_5_ru").
Установка и первая загрузка требуют сети; синтез после подготовки выполняется локально.
Скрипт проверяет вход, ограничивает абзац 900 символами и эпизод пятью минутами.
Исходный MP3 заменяется только после успешного синтеза и обработки.
