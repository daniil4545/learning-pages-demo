# Перенос коллекции

Локальные оригиналы сохранены. В публичной библиотеке находятся отдельные учебные копии.
Стандарты оформления и содержания не менялись.

## Перенесено

- Четыре лекции серии о локальных моделях.
- Понимание системы.
- Нотации схем.
- Наблюдаемость: только теория, без практики на рабочих серверах.
- Реверс-инжиниринг устройств.

Из копий убраны рабочие адреса, внутренние ссылки, планы изменений и названия закрытых кейсов.
Условные примеры помечены. Версии инструментов и измерения сохранены на дату исходных страниц.
Миграция не является повторной проверкой всех технических утверждений и внешних ссылок.

## Исключено по назначению

- `llm-foundation.html`: подготовка рабочего проекта и материал к встрече.
- `quality-checks.html`: отчёт о текущих проверках и план изменений.
- `metrics-guide.html`: исследование действующих метрик и изменения процесса.
- `st-hardware-llm.html`: материал для решения о закупке.
- `catalog-audit.html`: отчёт об инвентаризации локальных файлов.

Их теорию можно оформить отдельными лекциями по явному запросу.
Старый локальный каталог не публикуется: он содержит ссылки на рабочие документы.
