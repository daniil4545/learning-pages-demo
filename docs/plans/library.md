# Общая библиотека лекций

Цель: готовить лекции на Mac и читать их через GitHub Pages с любого устройства.

## Границы

- В библиотеку входят явно заказанные учебные лекции.
- HTML-спецификации, материалы заказчику, отчёты и исследование к решению сюда не входят.
- Стандарты theory.md, html-pages.md и шаблон page.html сохраняются.
- Запрос новой лекции включает сбор материала и публикацию в библиотеке.
- Аудио требует отдельного вопроса владельцу для каждой лекции. Новое аудио создаём только по отдельному запросу. Пробная лекция о библиотеке включает подкаст по прямому запросу владельца.
- Сайт и репозиторий публичные. Рабочие адреса, персональные данные, ключи, закрытые метрики и внутренние подробности не публикуем.
- При переносе сохраняем оригиналы и чужие незакоммиченные изменения.

## Устройство

Один существующий репозиторий и адрес Pages. В site находятся только публичные файлы.
Сборщик на Python из стандартной библиотеки создаёт каталог из library.json.
Каждая лекция остаётся самостоятельным HTML по существующему стандарту.
Общая навигация и необязательный плеер подключаются поверх страницы.
Наличие аудио определяется записью в каталоге; пустого плеера нет.
Отдельного переключателя скорости нет. Используем штатное управление браузера.
Короткий общий скилл связывает существующие инструменты подготовки и публикацию.

## Приёмка

1. Все страницы каталога доступны на публичном сайте.
2. Между лекциями работают относительные ссылки и якоря.
3. Страницы без аудио не показывают плеер.
4. Новую страницу можно добавить записью в каталоге и командой сборки.
5. Проверка отвергает отсутствующий файл, выход за папку сайта и битую локальную ссылку.
6. На телефоне и компьютере работают каталог и возврат в библиотеку.
7. Публичные копии не содержат рабочих адресов и закрытых сведений.
8. Инструкция различает лекцию и HTML-спецификацию, отдельно спрашивает об аудио.

## Проверка

python3 library.py build
python3 library.py check
python3 -m unittest discover -s tests -v
